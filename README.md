## Must download to work
### [Python](https://www.python.org/downloads/)

## Installation

1. Clone the repo
   ```
   git clone https://github.com/TheBaNoNa123/OpenMeteo.git
   ```
2. Install packages
   ```
   pip install requests
   pip install pytest
   ```
## Run Program
   ```
    cd src
    python main.py
   ```
